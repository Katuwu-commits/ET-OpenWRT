# Arcadyan Meteor 2 5G CPE (MediaTek MT6890/T750) - Device Tree Source

This directory contains the Device Tree files for the Arcadyan Meteor 2 5G CPE (MediaTek T750 / MT6890).

### Files:
- `mt6890-arcadyan-meteor-2.dts`: Extracted live Device Tree Source file from the Arcadyan CPE serial console.

Copy your `arcadyan_stock.dts` from the USB backup drive to this folder as `mt6890-arcadyan-meteor-2.dts` and commit to trigger the GitHub Actions build!
